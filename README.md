### Objetivo

Mediante el desarrollo de este proyecto, las personas estudiantes aplicarán los conceptos de arquitectura de multiprocesadores (MP). El objetivo principal consiste en diseñar e implementar un modelo de simulación de un interconnect para analizar el impacto en el rendimiento de los protocolos de coherencia de caché frente a patrones de acceso a memoria de algoritmos paralelos.
